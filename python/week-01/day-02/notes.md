# Day 2 - Data Types & Type Conversion

## Data Types
- `str` → Text
- `int` → Whole numbers
- `float` → Decimal numbers
- `bool` → True / False

## Functions Learned
- `type()` → Check data type
- `input()` → Take user input
- `int()` → Convert to integer
- `float()` → Convert to float
- `str()` → Convert to string
- `bool()` → Convert to boolean
- `split()` → Split input into multiple values
- `strip()` → Remove leading/trailing spaces

## Important
- `input()` always returns a `str`.
- Convert input before performing calculations.
- `split()` separates input into multiple values.
- `strip()` removes unwanted spaces.

## Challenge
- Learned to take multiple inputs.
- Used `split()` and `strip()`.
- Converted input to the required data type.
