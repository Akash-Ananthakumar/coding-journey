# Day 3 - Operators

## Arithmetic Operators
- `+` → Addition
- `-` → Subtraction
- `*` → Multiplication
- `/` → Division
- `//` → Floor Division
- `%` → Modulus (Remainder)
- `**` → Exponentiation (Power)

## Comparison Operators
- `==` → Equal to
- `!=` → Not equal to
- `>` → Greater than
- `<` → Less than
- `>=` → Greater than or equal to
- `<=` → Less than or equal to

## Assignment Operators
- `=` → Assign
- `+=` → Add and assign
- `-=` → Subtract and assign
- `*=` → Multiply and assign
- `/=` → Divide and assign
- `%=` → Modulus and assign
- `**=` → Exponentiate and assign
- `//=` → Floor divide and assign

## Functions Learned
- `abs()` → Absolute value
- `max()` → Largest value
- `min()` → Smallest value
- `round()` → Round a number
- `pow()` → Raise a number to a power

## Important
- `/` always returns a `float`.
- `//` removes the decimal part.
- `%` returns the remainder.
- `**` calculates powers.
- Python follows BODMAS (operator precedence).
- `f""` (f-string) is used to insert variables into strings.
- `\n` creates a new line.
